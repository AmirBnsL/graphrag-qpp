# Domain Docs

How engineering skills consume this repo's domain documentation.

## Before exploring, read these

- **`GLOSSARY.md`** at the repo root.
- **`docs/adr/`**: read ADRs touching the area of work.

If any of these files do not exist, proceed silently.

## File structure

Single-context repo:

```
/
├── GLOSSARY.md
├── docs/adr/
│   └── 0001-slug.md
└── src/
```

## Use the glossary's vocabulary

When naming domain concepts, use the exact term as defined in `GLOSSARY.md` and adhere to `_Avoid_` directives.
